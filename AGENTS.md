# Komal publishing repository instructions

This repository is the publishing platform for Komal Nakrani's original,
role-based books and learning material.

## Authoritative boundary

- The visual system was intentionally copied from AlpeshNakrani.com.
- Preserve the light editorial UI, spacing, typography, components, and route
  patterns unless a verified usability issue requires a focused change.
- No inherited Alpesh identity, biography, books, manuscripts, figures,
  recommendations, solution pages, commercial links, or claims belong to Komal.
- Every Komal book must be researched and written fresh. Never bulk-relabel old
  material or imply transferred authorship.

## Operating order

1. Read `project-control/role-factory/FACTORY-STATE.md`.
2. Read the active GitHub issue and the role's `ROLE-STATE.md` when present.
3. Finish all Komal publishing and book work before resuming Abhyaas.
4. Work one executable issue at a time and leave verification evidence.

## Product boundary

- Komal teaches and publishes optional preparation material.
- Abhyaas independently certifies competence.
- A Komal book may map to a certification standard, but buying or reading it
  must never be required to sit an Abhyaas exam.

## Required checks

- Keep the production build passing.
- Publish only reviewed Komal-owned material.
- Preserve source provenance, edition identity, errata, and role mappings.
- Do not commit generated output, secrets, dependency folders, or nested repos.
