## ⚡ Why We Built With Astro

Modern web development has suffered from client-side bundle inflation. Traditional single-page applications (SPAs) ship megabytes of JavaScript just to display static text and images, leading to poor mobile performance and low Lighthouse scores.

**Astro changed everything.** By shifting rendering overhead to build time and serving zero JavaScript by default, Astro delivers pre-rendered HTML that loads instantly on any network.

## 📖 Key Takeaways from Astro Docs

When building our theme architecture, we relied heavily on core patterns from the official [Astro Documentation](https://docs.astro.build). Here are the foundational concepts powering our templates:

<AstroDocRef

  docUrl="https://docs.astro.build/en/concepts/islands/"
  summary="Astro Islands extract UI elements into isolated client components (React, Vue, Svelte, Alpine) that only load JavaScript when explicitly needed via directives like client:load or client:visible."

<AstroDocRef 
  topic="2. Type-Safe Content Collections & Content Layer"
  docUrl="https://docs.astro.build/en/guides/content-collections/"
  summary="Content Collections allow you to manage local Markdown, MDX, or JSON files with full Zod schema validation and automatic TypeScript type generation."
  codeSnippet={`// src/content.config.ts
import { defineCollection, z } from 'astro:content';
import { glob } from 'astro/loaders';

export const collections = {
  blog: defineCollection({
    loader: glob({ pattern: '**/*.mdx', base: './src/content/blog' }),
    schema: z.object({
      title: z.string(),
      pubDate: z.coerce.date(),
    }),
  }),
};`}

## 🛠 Code Component Showcase: Astro vs Traditional Frameworks

Let's look at a code comparison showing how Astro handles static components versus traditional framework client-side hydration:

<CodeComparison 
  astroTitle="Astro Zero-JS Component"
  traditionalTitle="React Hydrated Client Component"
  astroCode={`---
// Executed at BUILD TIME only
const { title, date } = Astro.props;
---
<article class="post">
  <h2>{title}</h2>
  <time>{date}</time>
</article>`}
  traditionalCode={`import React from 'react';

// Runs on server AND re-hydrates in browser
export default function Post({ title, date }) {
  return (
    <article className="post">
      <h2>{title}</h2>
      <time>{date}</time>
    </article>
  );
}`}
/>

<Callout type="astro" title="Notice the Zero-JS Output">
In the Astro example above, zero JavaScript is sent to the client browser. The resulting output is raw, hyper-optimized HTML and CSS.
</Callout>
