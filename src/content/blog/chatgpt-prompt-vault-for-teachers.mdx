## The CREO Formula: How to Write AI Prompts That Actually Work

To get high-quality outputs from AI models, you don't need a computer science degree. You just need to structure your prompts using the **C-R-E-O Formula**:

```
┌────────────────────────────────────────────────────────────────────────┐
│ THE C-R-E-O PROMPT FORMULA │
├─────────────────┬──────────────────────────────────────────────────────┤
│ 1. Context (C) │ Define grade level, subject, and student learning background│
│ 2. Role (R) │ Assign AI role (e.g., "Act as an expert 3rd-grade teacher")│
│ 3. Explicit (E) │ Set strict boundaries (word count, reading level, tiers) │
│ 4. Output (O) │ Request exact format (Markdown table, bullet list, quiz) │
└─────────────────┴──────────────────────────────────────────────────────┘
```

## Category 1: Lesson Planning & Curriculum Differentiation Prompts

### Prompt 1.1: 3-Tier Differentiated Activity Generator
```text
Act as an expert primary school teacher. Here is my lesson objective: [Insert Objective, e.g., Understanding food chains and ecosystems]. 

Generate a 45-minute lesson plan for a 4th-grade class with 3 differentiated student activity stations:
- Tier 1 (Support): Visual matching activity using animal picture cards.
- Tier 2 (On Target): Food web diagram worksheet with word bank.
- Tier 3 (Extension): Environmental impact problem-solving scenario where students analyze what happens when a top predator is removed.
Include a 3-question Exit Ticket format at the end.
```

### Prompt 1.2: Inquiry-Based Science & STEM Experiment Outline
```text
Act as a middle school STEM teacher. Create an inquiry-based experiment outline for a lesson on [Topic, e.g., Chemical vs. Physical Changes]. The experiment must use low-cost household materials (baking soda, vinegar, cups). Include a student observation table and 3 reflection questions.
```

## Category 3: Empathetic Parent Communication Email Prompts

### Prompt 3.1: Constructive Academic Progress Email
```text
Act as a compassionate primary teacher. Draft an email to a parent regarding [Student Name]. 

Structure:
1. Warm opening praising [Positive Trait, e.g., helpfulness during group work].
2. Gentle explanation of [Academic Challenge, e.g., falling behind in reading comprehension scores].
3. Offer 2 collaborative, simple strategies we can implement together at school and home.
Keep the tone empathetic, professional, and reassuring.
```
