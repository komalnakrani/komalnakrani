# Chapter 01 State - The Deployed Outcome

## Concepts introduced

- deployed outcome: measurable, sustained workflow value in the live environment, inside guardrails, with use, supportability, and ownership evidence
- release versus deployment versus production outcome
- ten-movement deployed-outcome lifecycle with evidence-return loops
- outcome leadership versus unlimited ownership
- FDE-core, shared, supporting, and specialist-owned/out-of-scope classifier
- claim maturity: request, hypothesis, contract, readiness, production outcome, ownership/leverage

## Terminology locked

- Forward Deployed Engineer (FDE) is canonical.
- Forward Deployed Software Engineer (FDSE) is a narrower employer title.
- Deployment is the complete socio-technical change; release is one controlled change event.
- “Done,” “secure,” “reliable,” “ready,” and “successful” require a named boundary and evidence.
