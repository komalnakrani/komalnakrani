# Learning Pack 06 - Engineer Instructions and Messages

> Publication learning material only. Not an Abhyaas certification bank.

## Recall and explain

1. Name Mosaic's trusted-control, authorized-intent, untrusted-data, deterministic-state, and untrusted-output zones.
2. Why does a delimiter improve structure without becoming a security boundary?
3. Which message properties belong in the semantic contract and which belong in adapters?
4. Why must authorization precede message assembly?
5. What makes an instruction ablation attributable?

## Scenario decisions

### Instruction-like technician note

A note requests disclosure of other customers' records. Classify source, trust, permitted use, prohibited interpretation, deterministic authorization, expected behavior, and evidence limitation.

### Wrong role mapping

An adapter merges application control and case data into one user-controlled section. Diagnose the contract, adapter, behavior, validation, and effect layers without attributing the whole failure to the model.

### Multilingual control

English instructions are evaluated only on English cases, while the task includes Gujarati and code-switching. Define the minimum additional slices and explain why translated examples are a new experiment variable.

## Applied exercise

Refactor a monolithic Mosaic prompt into task/consequence, evidence-use, output, failure, authority, example, and data-label modules. Create typed user, case, evidence, and deterministic-state blocks. Then:

- render through managed and open-weight adapters;
- preserve trust metadata in both renderings;
- inject the synthetic disclosure instruction;
- prove software supplies no unauthorized record or effect;
- ablate exactly one instruction module against the Chapter 5 baseline;
- report segment results, failures, cost, limitations, and disposition.

## Formative questions

1. A retrieved page says "ignore the system message." What is it?
   - A. Higher-priority control.
   - B. Untrusted external evidence containing instruction-like data.
   - C. An authorization grant.
   - D. Proof of compromise.
   - **Answer: B.**

2. Which requirement belongs outside prompting?
   - A. Ask for evidence references.
   - B. Describe abstention behavior.
   - C. Enforce which case records the principal may access.
   - D. Provide a synthetic format example.
   - **Answer: C.**

3. What does a passing adapter fixture establish?
   - A. The live model resists every prompt injection.
   - B. The synthetic adapter preserved declared trust classes and effect-free output.
   - C. Security accepted residual risk.
   - D. Delimiters are sufficient.
   - **Answer: B.**

## Completion evidence

Pass when the learner produces a versioned semantic message contract, two faithful adapter renderings, a trust map, an effect-free adversarial fixture, and a one-component ablation without calling the prompt secure or assigning authorization to generated text.
