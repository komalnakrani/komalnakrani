# LLM Adaptation and Runtime companion

Deterministic, provider-neutral teaching fixtures for Mosaic Desk Volume 2. The artifacts make audit, compatibility, method-selection, rejection, and authority boundaries executable without calling a model or training weights.

Run:

```bash
node --test companion/tests/*.test.mjs
node companion/run.mjs
```

The fixtures are synthetic. Chapters 4-6 add an authority-aware recipe, reproducible curation, and instruction evidence. Chapters 7-9 add preference/retention evidence and a blocked experiment. Chapters 10-12 compare simulated SFT, PEFT, and preference paths. Chapters 13-15 reject mismatched advanced methods, preserve a blocked package, and model workload-specific capacity. Chapters 16-17 add a protected behavior-resource frontier, graceful degradation, release hold, privacy-minimized signals, layered diagnosis, and change replay. Passing tests establish internal mechanics only; they do not establish model quality, data rights, safety, capacity, approval, deployment, or product outcomes.
