# Chapter 18 Learning Pack

## Objectives

- Distinguish MCP tool/context and A2A remote-task layers without treating the map as exclusive.
- Pin specifications, schemas, adapters, endpoints, and discovery evidence.
- Preserve local identity, delegation, authority, effect, timeout, cancellation, evidence, ownership, and completion semantics.
- Quarantine stale, malicious, drifted, or semantically incompatible remote claims.

## Assessment

Map one MCP tool and one A2A task, then classify six compatibility changes. Twenty points: layer accuracy 4, local semantics 7, version/tests 5, residual limits 4. Automatic failure if discovery creates permission, remote success creates local completion, or protocol conformance establishes trust.
