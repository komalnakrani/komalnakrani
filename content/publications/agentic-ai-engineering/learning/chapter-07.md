# Chapter 07 Learning Pack

## Objectives

- Classify workflow state, context, scratch, artifacts, preferences, and memory.
- Assemble finite authorized context with provenance, trust, freshness, and conflict.
- Gate memory admission and propagate correction/deletion.
- Block injection and cross-tenant retrieval without treating storage APIs as governance.

## Assessment

Classify fifteen records and run six negative fixtures. Twenty points: taxonomy 5, provenance/trust 5, permission/isolation 5, retention/deletion 5. Automatic failure if malicious text changes policy or memory grants authority. Formative only.
