# Forward Deployed Engineering Lab Kit

This deterministic local kit supports the optional Komal course. It imports the provider-neutral companion used by the book and adds six course-specific scenario compositions.

Run one module:

```sh
npm run course:fde -- --module 01
```

Run the complete capstone evidence sequence:

```sh
npm run course:fde
```

Run all lab assertions:

```sh
npm run test:course:fde
```

All identities, data, timings, incidents, decisions, and outcomes are synthetic. Passing these tests is not a certification result and provides no evidence about a real customer, provider, model, integration, security posture, accessibility, performance, recovery target, adoption, or production outcome.
