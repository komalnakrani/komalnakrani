# Volume 2 Chapter 1 Blueprint — Start From a Frozen Behavior Baseline

## Frozen identity and dependency

- Chapter: `V2-01`; milestone: `MD-09`; domains: `LLME-K01`, `LLME-K06`, `LLME-K07`.
- Prerequisite: accepted `MD-08` managed/hosted release and adaptation handoff.
- Forward dependency: Chapters 2–3 inspect artifacts and choose an intervention.
- Reader transformation: from “tune the model” intuition to a falsifiable adaptation hypothesis against frozen evidence.

## Measurable objectives

The reader can reconstruct the complete Volume 1 baseline; state target, retention, control, and resource criteria; distinguish retrieval/prompt/schema failures from adaptation-sensitive failures; preserve managed/open-weight comparability; and write rejection/stopping evidence.

## Concept sequence and skill procedure

Handoff audit → exact baseline identity → repeated failure pattern → alternative-layer diagnosis → adaptation hypothesis → predicted evidence → forbidden regressions → stop/reject criteria. Procedure: replay cases; freeze artifacts; isolate residuals; test simpler repairs; state mechanism hypothesis; define success and disconfirmation before training.

## Mosaic Desk transition and failure injection

- Incoming: `MD-08` release/migration dossier and residual multilingual shorthand failures.
- Failure injection: retrieval and template settings change while an open-weight checkpoint is introduced, making “training gain” uninterpretable.
- Outgoing: frozen cross-volume behavior ledger, open-weight base candidate, adaptation hypothesis, protected criteria, and audit gaps for `MD-09`.

## Dual path, authority, and non-scope

The managed Volume 1 system remains a behavioral comparator; Volume 2 primarily uses open-weight artifacts because weights/runtime are in scope. Comparable outcomes do not require identical internals. Product/domain set desired behavior; data/legal/privacy/security and platform retain authority. Non-scope: selecting a method or modifying weights.

## Practice and assessment

Exercise: Audit a contaminated handoff, restore one frozen comparison, and write a falsifiable hypothesis. Pass when simpler layer fixes are tested, protected criteria are explicit, and no training begins.
