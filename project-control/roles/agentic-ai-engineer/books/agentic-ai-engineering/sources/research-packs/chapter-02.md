# Chapter 02 Research Pack — Earn the Right to Use Autonomy

## Frozen job and evidence question

Compare a deterministic workflow, assisted workflow, single agent and
multi-agent system by ambiguity, feedback, consequence, cost and
controllability. The decision is the least complex adequate execution model,
recorded in `AR-01` with rejected alternatives.

## Claims to carry

- `AGE-BCLM-003`: a less autonomous baseline is required before autonomy is
  justified.
- `AGE-BCLM-004`: “multiple agents generally improve quality” is disputed and
  must not appear as an accepted proposition.

## Source findings

- `AGE-BSRC-001` recommends agents where deterministic approaches struggle and
  emphasizes starting incrementally. `AGE-BSRC-002` favors simple composable
  patterns and distinguishes fixed workflows from autonomous control.
- `AGE-BSRC-023` frames excessive functionality, permissions and autonomy as
  risk contributors. It supports bounding—not a ban on agents.
- `AGE-BSRC-036` supports contextual risk decisions and explicit alternatives.
- `AGE-BSRC-013` documents a multi-agent research workload with reported
  benefits and substantially higher token use. The result is a bounded case,
  not a universal rule. `AGE-BSRC-042` documents patterns only.

## Decision matrix research

The Phase 07 blueprint must require a table with: task variability; observability
of intermediate state; rule completeness; time horizon; consequence of error;
tool uncertainty; feedback latency; human availability; performance baseline;
and failure containment. Each candidate architecture receives a measurable
prediction and rejection reason. “Leadership wants a demo” is not evidence.

## Case and FieldOps Relay research use

Primary: `AGE-CASE-012`. Run the same synthetic scheduling task through a fixed
state machine first. The architecture says it handles a fictional 92%; that
number must be labeled an injected scenario, then reproduced by a generated
task set in the eventual companion before it becomes book evidence.

Contrast: `AGE-CASE-001`. Anthropic's parallel research system is appropriate
because information branches can be explored independently. FieldOps contains
shared inventory effects and ownership constraints; those differences are the
reason transfer is not automatic.

## Failure and evaluation plan

Inject: leadership requests a “swarm”; missing tool feedback; a task with a
fully enumerable state machine; a high-consequence irreversible action; and a
parallelizable information-gathering task. Score completion, policy, unnecessary
actions, elapsed time, tool calls, coordination errors, and evidence quality.

## Phase 07 blueprint seed

Sequence: autonomy is a liability/benefit exchange -> architecture ladder ->
decision matrix -> FieldOps baseline experiment -> disputed multi-agent claim ->
rejection log. Project artifact must record what would falsify the chosen level.
Use `F02.1` as required; `F02.2` only if the final blueprint needs a visual
counterexample. No vendor logo, product screenshot, or invented performance
number.

## Gaps to keep visible

No current primary source provides a generally valid autonomy-selection
threshold. The matrix is a professional decision method whose predictions must
be evaluated in the local environment.
