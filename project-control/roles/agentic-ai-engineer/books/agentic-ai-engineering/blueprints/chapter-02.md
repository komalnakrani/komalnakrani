## Skill procedure and current examples

1. Make completion and consequence observable.
2. Implement or specify the fixed baseline first.
3. List task variations the baseline cannot represent economically.
4. Predict the exact benefit and cost of each higher level.
5. Hold task set, tools, policy, and budget constant when comparing.
6. Reject any level lacking measurable benefit or credible containment.
7. Record what future evidence would reverse the decision.

Current examples: OpenAI/Anthropic architecture guides and Google ADK
multi-agent patterns are dated illustrations, not a ranking. `AGE-CASE-001`
transfers only when work branches can be explored independently. Durable
principle: complexity must answer a measured task/control need. Volatile:
provider frameworks, model capability, token economics, and reported vendor
metrics.

## Scenario, failure injection, mistakes, and trade-offs

FieldOps fixed workflow handles the injected 92% of synthetic tasks; leadership
requests a swarm for presentation value. Fault set: missing feedback, fully
enumerable task, parallel information search, high-consequence irreversible
effect, and shared scarce stock. Common mistakes: treating novelty as value,
changing task/harness during comparison, reporting average success only, and
calling multi-agent a maturity stage. Trade-offs: flexibility versus
predictability; parallel elapsed time versus tokens/coordination; autonomy versus
review burden.
