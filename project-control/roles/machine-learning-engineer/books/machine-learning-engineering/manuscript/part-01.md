# Part 1 — Bench Zero: Define the Workload

## Bench Setup

The workbench opens in `UNORIENTED`. There is an approved purpose to examine,
but no learning workload deserves to exist merely because data or a modeling
idea is available. This part locates the MLE decision, contracts intended and
excluded use, names decision rights, retains a runnable incumbent, and ties
acceptance targets to consequences. The strongest correct outcome may be
`NO-ML` or `HOLD`.

## Part decision question

**Is there an owned, bounded learning decision with a retained incumbent and
explicit authority map?**

The answer must name the decision influenced by the workload, population,
incumbent, consequences, constraints, and owners. A technically attractive
candidate cannot repair an absent purpose or missing authority.

## Incoming evidence

`BL-ENTRY` is a fixed synthetic orientation fixture, not proof of an approved
real project. The reader must bring an approved purpose statement or explicitly
record that it is absent. No model file, metric, provider account, or dataset is
accepted as a substitute.

## Part map

- [Chapter 1](chapter-01.md) produces `BL-00`, the workload orientation charter,
  and separates MLE evidence work from adjacent decisions.
- [Chapter 2](chapter-02.md) produces `BL-01`, a versioned task-and-authority
  contract with intended use, exclusions, population, constraints, owners, and
  a fail-closed path.
- [Chapter 3](chapter-03.md) produces `BL-02`, retaining the runnable incumbent,
  consequence model, segment obligations, and acceptance target.

The route is `UNORIENTED → ORIENTED → CONTRACTED`; Chapter 3 remains
`CONTRACTED` while deepening the evidence.

## Part-exit Qualification Gate

`PASS` requires task, incumbent, consequence, authority, and `NO-ML`/`HOLD`
transfer to remain intact across all five ports. Managed mechanisms must export
the contract rather than hiding it in a provider UI. Classical and deep ports
must retain the incumbent despite different estimators. Edge work must keep
hardware, operations, safety, and domain owners external. Shared-platform work
must distinguish tenant workload decisions from fleet authority.

Return `HOLD` for a missing owner, unapproved purpose, unexecutable incumbent,
unnamed population, or consequence-free target. Return `REJECT` when the
contract shows ML is unjustified or prohibited. On `PASS`, `BL-02` enters
[Part 2](part-02.md); the gate does not authorize data access or model release.
