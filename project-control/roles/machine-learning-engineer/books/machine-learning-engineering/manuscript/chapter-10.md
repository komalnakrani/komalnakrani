Population evidence changes shape across ports. A managed system may expose only coarse provider slices. A classical pipeline can lose cell identity during feature aggregation. The transfer exercise uses a small synthetic matrix so every count can be checked by hand. Currentness is especially important for population definitions. Intended users, data collection processes, labeling rules, device deployments, tenant composition, and policy constraints can change even when code does not.
