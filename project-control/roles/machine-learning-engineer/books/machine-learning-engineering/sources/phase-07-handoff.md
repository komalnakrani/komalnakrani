  retires, or reviews a workload by itself.

  durability, volatility treatment, cases, architecture claims, boundaries,
  scenarios, domain, ports, and retained authority.
- Build deterministic failure mutations before explanatory prose: missing
  owners, stale hashes, broken reverse links, incompatible consumers, leakage,
  erased baselines, unsupported reproducibility, aggregate-only qualification,
  unsigned exceptions, residual serving paths, and self-approval must fail.
- Preserve the chapter milestone chain from `BL-00` through `BL-20`; no later
  artifact may silently repair or replace missing earlier evidence.
- Keep public case truth lanes and constructed case labels visible in every
  planned sidebar, lab, table, state machine, or capstone use.
- Keep dated current examples outside durable doctrine and retain every
  source-specific recheck trigger.
- Use semantic diagrams, tables, rails, ledgers, and state machines only where
  they clarify decisions; this handoff authorizes none of those assets yet.
