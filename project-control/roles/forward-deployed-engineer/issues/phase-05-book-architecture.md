# Phase 05 — Forward Deployed Engineering Book Architecture

## Objective

Design the complete learning architecture for the single original Komal book before chapter research or prose begins.

## Inputs

- Phase 01 role validation, evidence register, and adjacent-role boundary
- Phase 04 `SINGLE BOOK` decision, thesis, depth estimates, and non-overlap rules
- existing manuscripts: none
- deferred Abhyaas standard/objective map: later compatibility gate

## Work

- Lock title, subtitle, reader promise, audience, prerequisites, exit capability, terminology, and edition scheme.
- Define a lifecycle-based part/chapter progression with no padded chapters.
- Define the original running case, satellite-case requirements, and versioned capstone artifact progression.
- Map provisional Komal competency domains to chapters and evidence.
- Forecast visuals before manuscript writing.
- Define cross-reference, source, code, artifact, and case conventions.

## Acceptance criteria

- [x] The architecture preserves the locked single-book thesis.
- [x] Every chapter passes at least one chapter-existence test.
- [x] Entry audience and exit capability are explicit and credible.
- [x] Every provisional competency domain maps to primary chapters and observable evidence.
- [x] The project grows as one coherent deployment dossier rather than disconnected toys.
- [x] Case-study requirements prevent a single industry or AI pattern from becoming universal.
- [x] Visual forecast supports decisions, architecture, sequence, comparison, or diagnosis.
- [x] Terminology and version conventions are locked.
- [x] No inherited manuscript, MLOps volume shape, or Alpesh content is reused.

## Verification

- Review chapters against the existence test and adjacent-role boundary.
- Validate CSV structure and domain/chapter references.
- Check project milestones consume and extend prior artifacts.
- Run `npm run validate:publications` and `git diff --check`.

- `project-control/roles/forward-deployed-engineer/books/forward-deployed-engineering/competency-to-chapter.csv`
- `project-control/roles/forward-deployed-engineer/books/forward-deployed-engineering/project-map.md`
- `project-control/roles/forward-deployed-engineer/books/forward-deployed-engineering/visual-forecast.md`
- updated `project-control/roles/forward-deployed-engineer/ROLE-STATE.md`

## Handoff

Phase 06 can create chapter-specific research packs against a frozen chapter list, evidence target, project dependency, and visual plan.
