# Chapter 05 Blueprint — Scope the First Safe Production Path

## Purpose and exit capability

The reader can select and defend a small end-to-end production path, expose dependencies and uncertainty, sequence reversible evidence gates, control change, and stop unsafe or unjustified work.

## Prerequisites and non-scope

- Prerequisite: `OA-03` outcome contract and decision rights.
- Non-scope: generic project management, commercial estimation, prototype exposure to unacceptable risk, or “MVP” as omitted production obligations.

## Concepts, skills, and decision models

- Scope cone: request → outcome relevance → risk → dependencies → representative boundary → reversible slice.
- Four buckets: must prove, must build, defer, reject; uncertainty-to-experiment map.
- Dependency owner/date/evidence; milestone entrance/exit/stop; change-control test.
- Skill: compare scope options by evidence gained, consequence, reversibility, time, dependency risk, and future debt.

## Architecture, implementation, and tools

- Define the representative vertical slice before detailed design; record required user, interface, data, identity, control, and operating boundaries.
- Current tools: issue trackers/roadmaps (`volatile`) may visualize sequence; canonical scope/dependency/risk records are tool-independent (`durable`).

## Scenario and artifacts

- Build `OA-04`: one equipment family, region, cohort, representative vertical slice, dependency network, risk register, milestones, experiments, exclusions, and change rule.
- Evaluate and reject/defer multilingual voice and automatic parts ordering unless they pass outcome/risk/dependency tests.

## Cases and bounded use

- Regulated-document satellite derived from `R06-C006`/`R06-C007`: “small UI” is not small risk.
- Stopped-deployment satellite: fictional, explicitly constructed case where missing lawful/legitimate data access makes stop the correct outcome.
- `R06-C010`: primary capstone movement.

## Failures, mistakes, and tradeoffs

- Feature-list slicing, hidden dependency optimism, false precision, irreversible pilot, deadline-as-evidence.
- Tradeoff: broader representativeness versus smaller blast radius; choose the least exposure that still crosses the uncertainty-bearing boundary.

## Exercise and completion evidence

Rank three scope candidates and defend select/defer/reject. Inject the executive change request. Pass when the selected path traces to outcome/risk evidence and every dependency/stop condition has an owner.
