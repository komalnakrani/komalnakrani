# Komal screen-first book builder

This package graduates the approved Forward Deployed Engineering Field Expedition Log proof into a reusable full-book HTML-to-PDF system.

The first book configuration is `books/forward-deployed-engineering.mjs`. It reads the accepted publication manuscript and registries, binds the five-part route and 38 review PNG figures, renders a private 7 by 10 inch review edition, and verifies the result without changing the public publication manifest or download.

The full-edition design contract is `docs/superpowers/specs/2026-08-18-fde-full-screen-first-edition-design.md`.
