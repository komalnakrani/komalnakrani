# Bundled proof fonts

Retrieved from the official Google Fonts repository on 2026-08-18 for deterministic offline rendering.

- `barlow-condensed.ttf`: Barlow Condensed Bold, https://raw.githubusercontent.com/google/fonts/main/ofl/barlowcondensed/BarlowCondensed-Bold.ttf
- `source-sans-3.ttf`: Source Sans 3 variable roman, https://raw.githubusercontent.com/google/fonts/main/ofl/sourcesans3/SourceSans3%5Bwght%5D.ttf
- `ibm-plex-mono.ttf`: IBM Plex Mono Regular, https://raw.githubusercontent.com/google/fonts/main/ofl/ibmplexmono/IBMPlexMono-Regular.ttf

All three families are distributed under the SIL Open Font License 1.1. `OFL.txt` contains the license text.
